# Presupuestador

App web para armar presupuestos de sanitaria: formulario por pasos (Cliente → Materiales → Mano de obra → Viáticos → Condiciones) con vista previa en vivo de la hoja y salida en PDF y Word.

Hecha para una sanitaria real de Uruguay cuyo dueño hoy presupuesta en papel y después pasa todo a Word.

**Stack:** React + TypeScript (Vite) · Supabase · Vitest

## Correr en local

```bash
npm install
npm run dev
npm test
```
